# churn-prediction-service
End-to-end Telco customer churn prediction service: Scikit-learn preprocessing pipeline, MLflow experiment tracking and model registry, FastAPI inference endpoint, multi-stage Docker build, and pytest CI. Tuned for recall on the minority churn class.

**Problem statement.** The objective is to predict whether a telecom customer will churn in the next month, using the IBM Telco Customer Churn dataset (7,043 customers, 19 predictive features after removing the customerID identifier). The target is binary (Churn: Yes/No), with a 73.5%/26.5% class split. Because false negatives (missing an at-risk customer) are substantially costlier than false positives (an unnecessary retention offer), recall on the churn class is the primary operational metric, supported by F1 and PR-AUC. The model will be evaluated on a held-out stratified test set, and the decision threshold will be tuned on validation data to align with a retention team’s capacity. A secondary engineering goal is to make the entire preprocessing → training → serving path reproducible and containerized, so the model can be consumed via a REST API.
